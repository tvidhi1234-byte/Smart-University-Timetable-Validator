
# Smart University Timetable & Schedule Validation System

A web-based university timetable management system.

## Technologies
- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Features
- Interactive Dashboard
- Timetable Management
- Room Conflict Detection
- Faculty Conflict Detection
- Section Conflict Detection
- Room Capacity Validation
- CSV Import and Export
- Validation Reports

## Dataset
- Rooms
- Faculty
- Courses
- Sections
- Timetable

## Deployment

This application can be deployed using Streamlit Community Cloud.

Main file: app.py

## Project Type
Individual Mini Project
